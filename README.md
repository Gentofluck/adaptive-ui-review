# Методы адаптации интерфейсов под поведение пользователей

Сайт для задания 1 по курсу «Проектирование и развертывание веб-решений в эко-системе Python». За основу взял теоретическую часть своей НИР.

## Запуск

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```
